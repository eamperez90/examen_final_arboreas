##  Descripción

Un solo archivo `Main.java` con todo incluido: Nodo, BST y menú interactivo.


Manualmente:

```bash
mkdir -p out && javac -d out src/Main.java && java -cp out bst.Main
```

##  Opciones del menú

| Opción | Función |
|--------|---------|
| 1 | Insertar valor(es) |
| 2 | Buscar valor |
| 3 | Eliminar valor (3 casos) |
| 4 | Ver recorridos InOrder / PreOrder / PostOrder |
| 5 | Ver estructura del árbol |
| 6 | Información Big-O |
| 7 | Cargar datos de demo automáticamente |
| 0 | Salir |
